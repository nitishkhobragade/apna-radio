# 📻 Apna Radio (अपना रेडियो) — Vintage Transistor Player

> *"पुराने नगमे, वही पुरानी चाय की चुस्की और रेडियो की खनक।"*  
> A nostalgic, skeuomorphic 80s/90s Indian transistor and cassette player web application built with modern web technologies.

---

## ✨ Features

- 📻 **Authentic Vintage Hardware Aesthetics**:
  - Realistic teak wood texture cabinet with polished brass fittings.
  - Horizontally tilted chrome telescopic antenna and brass rivets.
  - Dual left/right acoustic hi-fi speaker grilles with animated diaphragm pulses.
- 📼 **Mechanical Cassette Bay & Spinning Reels**:
  - Realistic Side-A cassette tape with spinning gear spindles synced to the active audio state.
  - Displays dynamic album art, track details, and retro equalizer bars.
- 🎛️ **Illuminated AM/FM Frequency Tuning Dial**:
  - Amber-backlit tuning window with real-time illuminated needle tracking track progression.
- ☕ **Ambient Chai-Stall Atmosphere (टपरी साउंड्स)**:
  - Toggleable ambient background soundscape (gentle monsoon rain, kettle steam whistle, and ambient street noise).
- 🎶 **Custom YouTube Playlist Support**:
  - Load custom YouTube playlists or individual tracks via URL or Playlist ID.
  - Pre-curated collections of legendary Golden Era Bollywood and classic hits.
- ⌨️ **Keyboard Shortcuts & Tactile Controls**:
  - `Space`: Play / Pause
  - `←` / `→`: Skip backward / forward 10 seconds
  - `N` / `P`: Next / Previous track

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS (Utility-first custom textures & gradients)
- **Icons**: Lucide React
- **Media Engine**: YouTube IFrame API & Web Audio
